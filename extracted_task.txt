6.  Evaluation  Criteria  Weight  Criterion  
25%  Governance  correctness  —  no  agent  write  lands  on  main  without  approval;  ingest  is  idempotent;  commits  attributed  
20%  Extraction  quality  —  entities/edges  faithfully  represent  the  seed  docs;  metrics  captured  as  structured  proof  points,  not  blobs  
20%  Agent  output  quality  —  evaluator's  questions  (asked  live)  answered  accurately  from  graph  knowledge  only  
15%  Access  control  —  Cedar  roles  demonstrably  scope  what  each  agent  can  see  
10%  Dashboard  usability  —  a  non-engineer  can  find  a  fact  and  see  recent  changes  
10%  Engineering  hygiene  —  README  reproducibility,  clean  repo,  sensible  schema  
Evaluator  will  ask  two  unseen  logical  questions  through  the  agents/MCP  on  demo  day  and  
compare

from
